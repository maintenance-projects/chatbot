GPU 지표 보는 법 · 증설 판단 기준

이용률 100%는 정상입니다. 문서 분석(AI 추론) 중엔 GPU가 꽉 차 100%가 됩니다 — 자원이 잘 쓰이는 정상 상태이며, 그 자체로 증설 신호가 아닙니다.

증설이 필요한 신호는 다음이 함께 나타날 때입니다:

  • 이용률 90%↑ 시간 비율이 상시 높음(지속적인 포화) ← 처리량 한계
  • 메모리(VRAM) 사용률이 상시 높음(90%+) — LLM은 보통 메모리가 더 결정적 한계(OOM 위험)
  • 동시 사용 증가 시 응답 지연·대기 발생

지표 특성: 실시간 탭은 순간값(요청 중 100%는 정상), 이력은 샘플 기반입니다. 순간 100%보다 지속 비율·메모리·응답 지연으로 판단하세요. (이력 탭의 "이용률 90%↑ 시간 비율"이 핵심 지표)

GPU는 CPU처럼 '한 숫자 사용률'이 아닙니다. CPU %는 연산 능력에 비례하는 단일 값이지만, GPU는 여러 축으로 나눠 봐야 합니다:

  • 이용률(util) = GPU가 바쁜 시간 비율(연산 능력 아님) → 작은 작업이 계속 돌아도 100%가 됩니다.
  • 메모리(used/total) = 용량 사용률 — CPU %에 가장 가까운 선형 지표. LLM은 보통 메모리가 실질 한계.
  • 전력(draw/limit) = 실사용 강도. util 100%여도 전력이 낮으면 가벼운 작업입니다.
  • (참고) SM 점유율·텐서코어 = 진짜 '연산 용량 몇 %'(DCGM 필요), tokens/s·큐 = AI 처리량(모델 서버 메트릭). 둘 다 별도 연동 필요.

→ 그래서 이 화면은 전력·메모리를 앞세워 "얼마나 세게/많이 쓰는지"를 봅니다. 증설 판단은 메모리 + 전력 + 이용률 90%↑ 지속을 함께 보세요.
