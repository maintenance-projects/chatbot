01

로그인 · 세션 유지

로그인

  1. /at-i 페이지에서 관리자 ID와 비밀번호를 입력합니다.
  2. “자동 로그인”을 체크하면 10시간 동안 세션이 유지됩니다.
  3. 로그인 성공 시 좌측 메뉴가 활성화되고 세션 타이머가 시작됩니다.

세션 타이머

우측 상단 “연장” 버튼을 누르거나 주요 기능 호출 시 자동으로 갱신됩니다. 5분 미만이면 경고 색상으로 바뀝니다.

02

문서 관리 (/at-i/storage)

파일 업로드

  1. “업로드” 버튼을 눌러 파일 선택 후 등록합니다.
  2. 업로드가 끝나면 목록 상단에 최신 순으로 표시됩니다.
  3. 파일 상태를 “사용/중지”로 토글해 챗봇 노출 여부를 즉시 제어합니다.

검색 · 정렬

  • 파일명/등록자/태그로 검색 후 Enter 또는 검색 아이콘을 클릭합니다.
  • 정렬 옵션(등록일, 이름 등)과 오름/내림차순을 조합해 원하는 순서를 맞춥니다.

삭제 · 복구

  • 행 우측 “삭제”를 누르면 확인 모달이 뜹니다.
  • 삭제 후에도 이력은 로그로 남으므로 실수 시 관리자에게 문의해 복구 가능합니다.

TIP

여러 개의 파일을 한 번에 올릴 때는 50MB 이하로 나누면 업로드 실패를 줄일 수 있습니다.

03

통계 (/at-i/statistics)

요약 보기

기간을 지정하고 “조회”를 누르면 전체 사용량, 성공/오류 비율, 사용자 수를 요약 카드로 확인합니다.

일/시간대 분석

  • 일별 탭: 날짜별 호출 건수와 답변 성공률을 확인합니다.
  • 시간대 탭: 시간대별 피크 타임을 찾아 운영 인력을 조정합니다.

일별 차트 클릭

  • 일별 그래프에서 날짜를 클릭하면 시간대별 분포의 날짜가 자동으로 바뀝니다.
  • 선택된 날짜는 포인트가 강조되어 빠르게 확인할 수 있습니다.

상위 사용자

“사용자 랭킹” 표에서 자주 사용하는 계정을 확인하고 이상 패턴을 점검합니다.

엑셀 내보내기

필터 적용 후 “엑셀 다운로드”를 누르면 동일 조건으로 XLSX 파일이 생성됩니다.

04

계정 관리 (/at-i/master)

계정 추가

  1. “계정 추가” 버튼 클릭 → ID, 이름, 임시 비밀번호 입력.
  2. 권한(문서/통계/마스터)을 체크 후 저장하면 즉시 반영됩니다.

수정

목록의 “수정”을 눌러 이름, IP, 권한을 변경합니다. 저장 후 바로 적용됩니다.

삭제

“삭제” 클릭 → 확인 후 제거됩니다. 본인 계정은 삭제할 수 없습니다(SelfDelete 방지).

IP 제한

등록된 IP만 허용되도록 설정하면 외부 접속을 차단할 수 있습니다.

05

비밀번호 변경 · 로그아웃

비밀번호 변경

  1. 좌측 하단 열쇠 아이콘을 눌러 모달을 엽니다.
  2. 현재 비밀번호와 새 비밀번호를 입력 후 “변경”을 누릅니다.
  3. 성공 시 토스트 알림이 표시됩니다.

로그아웃

좌측 하단 화살표 아이콘을 클릭하면 세션이 즉시 종료되고 로그인 화면으로 이동합니다.

06

문제 해결 체크리스트

로그인 불가

  • 계정 잠금 여부를 마스터 관리자에게 확인합니다.
  • IP 제한이 있는 경우 등록된 장소에서 접속하는지 확인합니다.

파일 업로드 실패

  • 파일 크기와 확장자를 확인하고 50MB 이하로 분할 업로드해 보세요.
  • 동일 파일명을 덮어쓰면 최신 버전으로 교체됩니다.

통계가 비어 있을 때

  • 조회 기간이 오늘 포함인지 확인하고, 날짜를 넉넉히 선택해 다시 조회합니다.
  • 필터(사용자 ID 등)를 모두 해제한 뒤 재조회합니다.
