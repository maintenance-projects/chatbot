이용 안내

📘 AI 어시스턴트 이용 안내

👋 이렇게 사용하세요

채팅창에 궁금한 내용을 입력하세요.
AI가 등록된 문서를 분석해 답변을 제공합니다.

“관련된 자료를 찾을 수 없습니다”라는 답변이 나오면,
해당 내용이 아직 등록되지 않은 상태입니다.
👉 내가 가진 파일로 질문하려면 상단 개인문서 AI 분석 탭에서 파일을 올린 뒤 질문해 주세요.

🔍 검색 방식 안내

AI는 등록된 전체 문서를 대상으로 관련 내용을 찾아 답변합니다.

💡 이렇게 질문하면 더 좋아요

질문이 구체적일수록 답변이 더 정확해집니다.

  • ✔️ “2024년 매출 실적을 알려줘”
  • ✔️ “A제품과 B제품의 성능 차이는?”
  • ✔️ 한 번에 하나의 주제씩 질문하기

❓ AI가 다시 물어볼 수 있어요

질문이 모호한 경우, AI가 한 번 더 확인할 수 있습니다.

  • ❌ “그거 알려줘”
  • ⭕ “2023년 하반기 인사 정책 변경 내용을 알려줘”

👉 안내에 따라 조금 더 구체적으로 입력해 주세요.

📌 답변 출처 확인

답변 하단에서 참고한 문서와 페이지 정보를 확인할 수 있습니다.
전체 문서 검색 결과의 경우, 문서 다운로드 링크도 함께 제공됩니다.

ℹ️ 이용 시 참고해 주세요

  • AI는 등록된 문서 내용을 기준으로 답변합니다.
  • 문서에 없는 내용은 답변이 어려울 수 있습니다.
  • 중요한 수치나 날짜 정보는 원본 문서와 함께 확인하시는 것을 권장합니다.
  • AI가 되물은 후 10분 이내에 응답하지 않으면 대화가 초기화됩니다.
  • 질문 분석에 따라 답변까지 약간의 시간이 걸릴 수 있습니다.

📄 개인문서 AI 분석 이용 안내

👋 이렇게 사용하세요

내가 가진 파일을 올리고, 그 문서 내용에 대해 질문하거나 요약할 수 있습니다.

  1. 하단 도구의 문서 업로드를 누르거나, 대화창에 파일을 끌어다 놓아 올립니다. (여러 파일을 한 번에 올릴 수 있어요)
  2. 개인 문서함(#)을 열어 분석할 파일을 선택합니다.
  3. 선택한 문서를 기준으로 질문하거나 요약을 실행합니다.

📁 여러 문서를 함께 선택

개인 문서함에서 체크박스로 여러 파일을 선택할 수 있습니다. 선택한 뒤 하단에서 원하는 작업을 누르세요.

  • 질문 : 선택한 문서들을 대상으로 질문합니다.
  • 개별 요약 : 선택한 문서를 각각 요약합니다.
  • 통합 요약 : 선택한 문서들을 묶어 하나로 요약합니다.

📌 선택한 문서는 유지됩니다

문서를 선택하면 입력창 위에 문서 칩으로 표시되고, 같은 문서(들)로 연속 질문할 수 있습니다.
일부만 빼려면 해당 칩의 ×를, 다른 문서로 바꾸려면 문서함에서 다시 선택해 주세요.

💡 이렇게 질문하면 더 좋아요

질문이 구체적일수록 답변이 더 정확해집니다.

  • ✔️ “이 계약서의 계약 기간은?”
  • ✔️ “두 문서의 차이점을 비교해줘”
  • ✔️ 한 번에 하나의 주제씩 질문하기

📌 답변 출처 확인

답변 하단에서 참고한 문서와 페이지 정보를 확인할 수 있습니다.
PDF 출처는 눌러서 미리보기, 그 외 문서는 눌러서 다운로드됩니다.

ℹ️ 이용 시 참고해 주세요

  • 지원 파일 형식: PDF, HWP, HWPX, Word, Excel, PowerPoint 등
  • 업로드한 파일과 대화 기록은 7일간 보관됩니다.
  • 이미지 위주의 PDF는 내용 인식이 어려울 수 있습니다.
  • 답변을 기다리는 동안에는 새 질문·요약을 보낼 수 없습니다.
